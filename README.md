# Diana Flores Catering

A Spanish/English marketing website for Diana Flores's Mexican catering, pickup orders, desserts and sauces in Chihuahua. Customer calls to action open WhatsApp conversations.

## Purpose and status

The implemented site contains catering information, menu categories, product descriptions, an about section and responsive navigation. `/` redirects to `/es`; `/es` and `/en` are generated by the locale layout. This is a content and contact site: no checkout, order database, appointment system or server-side inquiry submission is tracked.

## Architecture and integrations

Next.js 16 App Router, React 19 and TypeScript generate a static site with CSS styling. `next.config.ts` sets `output: "export"` and disables server image optimization. The locale layout uses Playfair Display and Inter through `next/font/google`; the original starter's Geist description no longer describes the source.

WhatsApp calls to action are external links with prefilled text, not an API integration or automatic message delivery. There is no tracked database, authentication, payment service, email provider or runtime environment-variable configuration. Font fetching during a future build may require network access.
